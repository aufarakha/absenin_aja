# 📱 Absenin Aja

**Absenin Aja** is my personal project built out of frustration with the school attendance app and API.

The official system often feels:

* buggy
* unreliable
* vulnerable 
* and lacking useful features (doesnt have import qr image)

So instead of just complaining, I built my own version as an experiment.

---

## Purpose

* Learn Reverse Engineering & Android development
* Explore how attendance systems work
* Express my emotion through code

---

## Features

* Simple attendance interface
* Testing & simulation tools for development (spoof location, submit attendance for others)
* Cleaner user experience than the original app
